# Pilotes NEXUS 4D OS

Les pilotes servent à tester le système sur des missions réelles avant d'ajouter de nouvelles fonctionnalités.

## Règles

1. Un pilote commence par un contexte client explicite.
2. Les faits, inférences, hypothèses et inconnues restent séparés.
3. Aucun score ne prédit la performance commerciale.
4. Toute faiblesse observée doit devenir soit un correctif, soit un apprentissage.
5. Une fonctionnalité n'entre dans la roadmap que si le pilote révèle un besoin réel.

## Pilote 01

`ctprod-nexus4d-meta/` : première mission réelle de génération de leads pour une offre NEXUS 4D de CT PROD via Meta Ads.
