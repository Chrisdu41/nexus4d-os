# Angle Library

Un angle est une manière stratégique de cadrer un problème, un désir ou une offre.

## Familles initiales

- douleur explicite
- coût caché
- coût de l'inaction
- aspiration
- identité
- statut
- preuve
- démonstration
- comparaison
- objection
- mythe
- contre-intuitif
- erreur fréquente
- mécanisme
- histoire
- diagnostic
- checklist
- avant/après

## Règle
Deux formulations différentes qui reposent sur la même tension ne constituent pas deux angles différents.
