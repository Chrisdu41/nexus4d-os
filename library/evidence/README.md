# Evidence Library

La preuve réduit l'incertitude. Une promesse forte sans preuve correspondante augmente le risque de rejet.

## Familles de preuve

1. **Démonstration** — montrer le mécanisme ou le résultat.
2. **Donnée primaire** — résultat mesuré et attribuable.
3. **Cas client** — contexte, intervention, résultat, limites.
4. **Témoignage** — expérience attribuable et authentique.
5. **Autorité** — qualification réellement pertinente.
6. **Mécanisme** — expliquer pourquoi l'offre peut produire le résultat.
7. **Comparaison** — alternative clairement définie et honnête.
8. **Processus** — montrer la méthode, les contrôles et les étapes.

## Hiérarchie

`Claim → Reason to Believe → Evidence → Limitation`

## Interdits

- témoignage inventé ;
- métrique sans source ;
- causalité affirmée sur simple corrélation ;
- autorité hors sujet ;
- démonstration simulée présentée comme réelle.
