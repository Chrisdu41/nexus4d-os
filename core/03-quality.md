# Quality Standard

## Gates
1. Vérité — aucune donnée inventée.
2. Clarté — l'idée est comprise rapidement.
3. Différenciation — le livrable n'est pas générique.
4. Preuve — les claims importants ont un reason-to-believe.
5. Testabilité — l'hypothèse peut être invalidée.
6. Faisabilité — l'exécution respecte les ressources disponibles.
