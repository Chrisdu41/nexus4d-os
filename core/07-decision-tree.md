# Decision Tree

Si l'utilisateur demande un résultat métier, choisir une Mission. S'il demande une expertise isolée, un spécialiste direct est possible.

Données insuffisantes mais recherchables : rechercher. Données indispensables non recherchables : demander. Données non indispensables : expliciter l'hypothèse.

Avant un asset : vérifier audience, objectif, angle, preuve, canal et métrique.
