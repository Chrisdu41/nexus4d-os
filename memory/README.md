# Memory System

La mémoire ne stocke pas tout : elle stocke ce qui peut modifier une décision future.

Trois niveaux : Client Memory, Experiment Log, Learning Library.

Un apprentissage qualifié contient observation, contexte, qualité du signal, interprétation, explications alternatives, confiance, portée et date de révision. Un résultat isolé ne devient jamais une vérité universelle.
