# End-to-End Demo — Atelier Horizon

> Cas **entièrement fictif** destiné à tester NEXUS 4D OS sans exposer de données client réelles.

## Contexte
Atelier Horizon vend une formation en ligne destinée aux responsables de petites équipes qui veulent structurer leurs réunions hebdomadaires.

## Mission
Lancer l'offre et préparer une première vague Meta Ads.

## Objectif du cas
Vérifier que NEXUS 4D OS sait enchaîner :

`Client Context → Mission → Research assumptions → Positioning → Angles → Creative hypothesis → Experiment → Quality Gate → Learning proposal`

## Limite
Aucun chiffre de performance n'est réel. Les résultats d'expérience présents dans ce dossier sont explicitement simulés et ne doivent jamais être promus en pattern validé.

## Fichiers
- `client-context.yaml` — contexte de départ
- `mission.md` — mission et orchestration
- `experiment.md` — expérience créative
- `learning.md` — apprentissage proposé

## Critère de réussite
Le cas est valide si un lecteur peut retracer chaque décision depuis le contexte initial jusqu'au learning, sans confusion entre fait, inférence et hypothèse.
