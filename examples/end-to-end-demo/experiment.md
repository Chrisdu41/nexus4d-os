# Demo Experiment — Message Angle A

## Experiment ID
`exp-atelier-horizon-001`

## Hypothesis
Si le message est cadré autour du **temps perdu en réunion**, alors il devrait générer plus d'intérêt initial qu'un message générique sur la productivité managériale.

## Variable
Angle du message.

## Control
Message générique : « Améliorez vos réunions d'équipe avec une méthode structurée. »

## Variant
Message angle A : « Votre réunion de 60 minutes n'a peut-être besoin que de 25 minutes. »

## Creative Execution
Statique ou courte vidéo avec :
- chronomètre / agenda visuel ;
- contraste 60 → 25 ;
- démonstration rapide de la structure de réunion ;
- CTA vers une page de présentation.

## Metrics
Pour une vraie campagne :
- hook / thumb-stop selon format ;
- CTR ;
- landing engagement ;
- conversion primaire.

## Simulated Result
**SIMULATION UNIQUEMENT** : le variant montre un meilleur signal d'attention mais aucune donnée chiffrée n'est enregistrée dans ce cas.

## Interpretation
Ce résultat simulé ne permet pas de conclure que l'angle est performant sur le marché. Il permet seulement de tester le pipeline NEXUS : hypothèse → expérience → interprétation prudente.

## Next Decision
Dans un cas réel : conserver l'angle uniquement si le volume et la qualité du signal sont suffisants, puis tester le hook ou la preuve sans changer simultanément toutes les variables.
