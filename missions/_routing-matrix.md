## Règle de routing
Le nombre de spécialistes n'est pas un objectif. Mobiliser le minimum nécessaire pour franchir le prochain gate de décision.

## Séquence de dépendance
`Research/VOC → Positioning → Creative → Production → Distribution → Performance → Memory`

Un spécialiste aval ne doit pas compenser silencieusement une donnée stratégique manquante en amont.
