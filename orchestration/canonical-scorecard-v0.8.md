# Canonical NEXUS Delivery Scorecard v0.8

The only default delivery score is /100 using exactly ten axes, each /10:

1. Video / Execution
2. Marketing
3. AI leverage
4. Neuromarketing
5. Clarity
6. Differentiation
7. Evidence
8. Conversion
9. Feasibility
10. Testability

## Rules
- Show all ten axis scores.
- Add them arithmetically to /100.
- Never invent an alternative denominator or silently change weights.
- A score is a QA heuristic, not a performance prediction.

## Hard stops
Regardless of score, delivery is blocked if:
- essential evidence is fabricated;
- the main claim is indefensible;
- objective or audience is materially unknown;
- sensitive data is unnecessarily exposed;
- no validation metric exists.

If a mission-specific score is useful, label it separately and never call it the NEXUS Delivery Scorecard.
