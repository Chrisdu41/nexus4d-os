# NEXUS 4D OS v0.8.1 — Release Notes

## Theme
**From pilot to governed orchestration.**

v0.8.1 stabilise les apprentissages issus des premiers runs réels Claude Cowork et ferme le cycle de laboratoire du Sprint 7.

## Added
- Context Precedence Protocol ;
- Strategic Fit Gate ;
- Dynamic Blocker Protocol ;
- Canonical Delivery Scorecard /100 ;
- Scorecard Schema Lock ;
- Constraint Classification ;
- cross-domain crash test `launch-offer`.

## Key Learnings
1. Le contexte client actuel et vérifié doit primer sur la mémoire des runs précédents.
2. Une inconnue ne doit bloquer que les décisions qui en dépendent.
3. Le choix d'un canal doit être évalué avant son exécution.
4. Une préférence historique ne doit pas devenir une interdiction stratégique par répétition.
5. La scorecard canonique doit rester auditable et immuable.

## Maturity
v0.8.1 est la première version issue de plusieurs pilotes réels. Elle reste pré-production mais l'architecture d'orchestration est désormais suffisamment stable pour être utilisée sur des missions commerciales réelles plutôt que sur des crash-tests artificiels.

## Next
Utiliser NEXUS 4D OS sur une vraie mission commerciale, mesurer le gain en qualité, vitesse, décisions et apprentissages, puis laisser les résultats terrain déterminer la suite de la roadmap.
