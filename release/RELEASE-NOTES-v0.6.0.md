# NEXUS 4D OS v0.6.0 — Release Notes

## Theme
**From engine to cockpit.**

Cette release rend NEXUS 4D OS pilotable au quotidien en ajoutant une interface de mission, une spécification de workspace client et un protocole de validation Claude Cowork.

## Added
- Mission Cockpit ;
- cockpit JSON schema ;
- Client Workspace Specification ;
- v0.6 Release Checklist ;
- Claude Cowork Pilot Guide ;
- Sprint 6 acceptance tests.

## Maturity
v0.6 reste une version pré-production. Le Core, les Missions, les Specialists, la Memory et les Playbooks sont structurés, mais l'efficacité réelle doit être validée par des missions pilotes.

## Critical principle
Le système ne doit pas être jugé sur la quantité de contenu produit mais sur sa capacité à :
1. cadrer correctement la mission ;
2. distinguer le certain de l'hypothétique ;
3. produire une expérience testable ;
4. transformer le résultat en apprentissage réutilisable.

## Next
v0.7 devrait être guidée par les résultats du pilote Cowork, pas par l'ajout arbitraire de fonctionnalités.
