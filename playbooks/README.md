# NEXUS Playbooks

Les playbooks traduisent les missions en séquences reproductibles avec gates, spécialistes, sorties et mémoire.

## v0.5

- `00-playbook-contract.md` — contrat canonique
- `01-launch-offer.md` — lancement d'offre
- `02-meta-ads.md` — creative testing Meta Ads
- `03-video.md` — production vidéo NEXUS 4D

## Règle
Une Mission décrit **le résultat métier**. Un Playbook décrit **une manière reproductible d'y parvenir**. Un Specialist apporte **une expertise limitée**.

Les trois niveaux ne doivent pas être fusionnés dans un mega-prompt.
