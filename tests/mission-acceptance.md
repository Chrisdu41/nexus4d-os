# Mission Acceptance Tests — v0.2

Une mission passe l'acceptation si toutes les réponses ci-dessous sont **oui** ou explicitement marquées non applicables.

## Contract
- [ ] L'objectif business est explicite.
- [ ] L'audience est définie.
- [ ] La Definition of Done est observable.
- [ ] Les contraintes sont connues.

## Evidence
- [ ] Faits, inférences, hypothèses et inconnues sont séparés.
- [ ] Les données importantes ont une provenance.
- [ ] Aucun verbatim n'est fabriqué.
- [ ] Aucun claim de performance future n'est présenté comme certain.

## Strategy
- [ ] Le positionnement/message directeur est clair avant production.
- [ ] Les spécialistes mobilisés sont nécessaires à la mission.
- [ ] Les dépendances amont sont résolues ou signalées.

## Execution
- [ ] Chaque livrable sert un objectif précis.
- [ ] Chaque expérience teste une hypothèse formulée.
- [ ] KPI et règles de décision sont définis.

## Learning
- [ ] Les limites d'interprétation sont documentées.
- [ ] La prochaine action est explicite.
- [ ] Une entrée mémoire est proposée si l'apprentissage peut modifier une décision future.

## Failure condition
Une mission échoue automatiquement si elle invente une preuve, un chiffre, une source, un témoignage ou un résultat.
