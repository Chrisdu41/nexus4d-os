# Sprint 4 Acceptance Tests

## Client Context
- [ ] un contexte client peut être représenté sans données inventées ;
- [ ] les inconnues restent explicites ;
- [ ] les données sensibles peuvent rester hors dépôt ;
- [ ] chaque mission peut référencer les learnings actifs.

## Memory Engine
- [ ] une observation isolée ne devient pas automatiquement un pattern ;
- [ ] chaque learning possède au moins une preuve ;
- [ ] la confiance et le statut sont explicites ;
- [ ] un learning peut être challenged, superseded ou invalidated ;
- [ ] les explications alternatives sont conservées.

## Experiments
- [ ] chaque test contient une hypothèse falsifiable ;
- [ ] le KPI principal est défini avant lecture ;
- [ ] plusieurs variables modifiées empêchent une attribution causale abusive ;
- [ ] la décision suivante est documentée.

## Cowork Packaging
- [ ] `.skill` est traité comme artefact ;
- [ ] la source de vérité reste GitHub ;
- [ ] aucun dossier client sensible n'est packagé ;
- [ ] le package contient un seul dossier racine et un `SKILL.md` ;
- [ ] la version du package est explicite.
